# Projeto Integrador

Repositório público para reunir os artefatos do projeto e acompanhar sua evolução.

## Organização

| Pasta | Conteúdo |
| --- | --- |
| [prototipos](prototipos/) | Telas, fluxos de navegação e links dos protótipos |
| [diagramas](diagramas/) | Diagramas do sistema e seus arquivos editáveis |
| [src](src/) | Código-fonte do sistema |
| [docs](docs/) | Requisitos, planejamento, pesquisas e entregas |

## Como enviar arquivos pelo site

1. Abra a pasta correspondente ao material.
2. Clique em **Add file → Upload files**.
3. Arraste os arquivos ou clique em **choose your files**.
4. Escreva uma descrição curta da alteração, como `Adiciona diagrama de casos de uso`.
5. Clique em **Commit changes** e confirme, caso apareça uma segunda janela.

Se o GitHub solicitar uma branch, crie uma com um nome descritivo, como `docs/diagramas`, e abra um pull request para revisão do grupo.

## Participação do grupo

Qualquer pessoa pode consultar este repositório público. Para enviar alterações diretamente, os integrantes devem aceitar o convite de colaborador enviado pelo proprietário em **Settings → Collaborators → Add people**.

Use as **Issues** para registrar tarefas e os **Pull requests** para revisar alterações antes de incorporá-las.
