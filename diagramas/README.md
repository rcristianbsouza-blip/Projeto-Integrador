# Diagramas

Adicione aqui os diagramas do sistema, como casos de uso, atividades, classes e modelo de dados, conforme o escopo do projeto.

Sempre que possível, envie a versão exportada em PDF ou PNG e o arquivo editável correspondente, como `.drawio`, `.puml` ou `.mmd`.

Prefira nomes descritivos, como `casos-de-uso.pdf`.
